# Snapline 简体中文版

这是 Snapline 的独立简体中文构建项目。它不会修改上游仓库，也不会改动你电脑上已经安装的 Snapline。

- 上游项目： https://github.com/mohabujubara/snapline
- 上游许可证：MIT（构建时从上游同步，保留原作者版权声明）
- 构建方式：GitHub Actions 在 Windows runner 上拉取上游源码、应用本地化补丁并构建 Windows x64 安装包。
- 本项目只提供本地化补丁和构建工作流；每次构建使用工作流执行时上游 `main` 分支的源码。

## 获取构建包

1. 打开本仓库的 **Actions**。
2. 选择 **Build Snapline 简体中文版**，查看最近一次运行。
3. 运行成功后，打开该次运行页面底部的 **Artifacts**，下载 `Snapline-ZH-CN`。
4. 解压 ZIP。优先运行 `Snapline-1.6.1-zh-cn-Setup.exe`（版本号随上游更新）；也会附带便携版 EXE。

首次运行未签名的 Windows 程序时，SmartScreen 可能提示风险。请只在确认文件来自本仓库成功完成的 Actions 构建后再决定是否运行。

## 注意事项

- 这是社区本地化构建，不是 Snapline 官方发行版，也不代表上游作者背书。
- 安装包与原版使用相同的应用名称和数据目录，因此**不要同时运行两个版本**。安装中文版前，建议先完全退出原版并备份 `%LOCALAPPDATA%\Snapline`。安装包不会主动删除原版数据，但两版共享设置和截图数据目录。
- 首次测试建议先用便携版，且不要卸载原版。构建产物未经代码签名。
- 工作流会从公开的上游仓库拉取源码；构建依赖 GitHub-hosted Windows runner，不需要另开云主机或收费服务。
- 版权及许可文本见上游仓库的 `LICENSE`。

## 本地化范围

将设置语言中增加“简体中文”，并翻译 Snapline 主要菜单、设置、工具提示、编辑器和状态文字。上游新增文字如果没有对应翻译，会回退显示英文；因此每次更新上游后应复核界面，不能只凭构建成功就认定翻译完整。
